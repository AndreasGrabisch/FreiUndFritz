# Checkliste vor Montage / Ausbau

Vom **Bewohnerverein** beauftragt. Fachliche Stellungnahmen (Fluchtweg, Zylinder) bei der **Postbaugenossenschaft** bzw. Schließer/Brandschutz.

→ [Projektplan](projektplan.md) · [Mail Hausverwaltung](mail-hausverwaltung.md) · [Versicherung](versicherung.md)

---

## Organisation & Freigaben

- [ ] **Beschluss Bewohnerverein** zu Grundsatz, Budget und Phase (Protokoll)
- [ ] **Abnahme / Zustimmung Postbaugenossenschaft** schriftlich — pro Tür oder als Gesamtkonzept
- [ ] **Versicherung** — siehe [versicherung.md](versicherung.md); Stellungnahmen eingeholt
- [ ] **Projektgruppe** benannt: Projektleitung, Technik, Anny-Admin, Stellvertretung
- [ ] **Hausordnung / Nutzungsregeln** geprüft; Anpassung für elektronischen Zutritt falls nötig

## Fluchtweg & Sicherheit

- [ ] **Flucht- und Rettungswegplan** eingesehen; betroffene Türen dokumentiert
- [ ] **Glastüren Veranstaltungsraum** (Hof): bestätigt — **kein Nuki**
- [ ] **Kellertür nach draußen** (Kellergang, künftiger Gäste-Hauptweg):
  - [ ] Zylinder-Typ und Funktion dokumentiert
  - [ ] **Öffnung von innen** bei Abschluss von außen getestet
  - [ ] Stellungnahme Postbaugenossenschaft: Fluchtweg, Einsperrgefahr
  - [ ] **Baustelle:** wann Kellergang wieder nutzbar?
- [ ] Rettungsweg-Türen: **Not- und Gefahrenfunktion** dokumentiert

## Technik je geplanter Tür

- [ ] **Türtest:** Schlüssel innen steckend drehbar (Zweitschlüssel / Nuki-Probe)
- [ ] **Nuki-Maße:** Abstand Klinke ≥ 30 mm; Schlüssel ≤ 37 × 4 mm
- [ ] **Internet / WLAN 2,4 GHz** gemessen; Repeater eingeplant
- [ ] WLAN-Zugang für Nuki geklärt (Apartment-Pilot)
- [ ] **Fallback:** mechanischer Schlüssel, Nuki-Drehknauf, Ansprechpartner

## Veranstaltungsraum — Rechtliches

Siehe auch [rechtliches.md](rechtliches.md).

- [ ] **Art. 19 LStVG** — KVR München (☐ offen ☐ eingereicht ☐ nicht nötig)
- [ ] **Nutzungsart VR:** Gemeinschaftsraum vs. Veranstaltungsort
- [ ] **Häufigkeit / Art** Veranstaltungen dokumentiert
- [ ] **Raumgröße** (m²); bei >100 m²: zweiter Ausgang prüfen
- [ ] **Buchungsbedingungen / Hausordnung** angepasst
- [ ] Öffentlicher VR-Betrieb erst nach rechtlicher Klärung

## Pilot Apartment (Phase 1)

- [ ] Technik-Checkliste nur Apartment-Tür erfüllt
- [ ] Hardware beschafft (Lock Pro, Keypad, ggf. Repeater) ≤ 600 €
- [ ] Nuki-App: Montage, Remote Open, Keypad-PIN
- [ ] **Anny-Regel:** nur Apartment-Schloss
- [ ] Gästeanleitung: Hauszugang weiterhin manuell
- [ ] 2 interne + 2 externe Testbuchungen
- [ ] 2 Wochen Probebetrieb

## Nach Pilot (Phase 2+)

- [ ] Pilotbericht an Verein
- [ ] **Erneuter Vereinsbeschluss** je weitere Tür
- [ ] Checkliste pro Tür wiederholen
- [ ] Anny-Regeln erweitern (Kellergang + Zielraum), wenn möglich
